Core Cryptography & Security Concepts

Key principles for your internship presentation

#1. One-Way Hashing

A cryptographic hash function like SHA-256 maps arbitrary data to a fixed 256-bit digest. It is mathematically irreversible (one-way pre-image resistance) and features the avalanche effect: altering even a single bit in the input drastically alters the entire output digest.

#2. Cryptographic Salting

A salt is a 128-bit random string generated via a CSPRNG for every password. Salting ensures that identical passwords produce completely different hashes. This completely neutralizes Rainbow Tables (precomputed hash lookup tables) and prevents cross-user hash correlation.

#3. Key Stretching (PBKDF2)

Fast hash algorithms (MD5, raw SHA-256) can be computed billions of times per second on GPUs. PBKDF2 applies 100,000 iterations of HMAC-SHA256, intentionally forcing computational work that makes offline brute-force cracking exponentially slower and economically unfeasible.

#4. Shannon Entropy

Entropy (H = L × log2(R)) quantifies the information density and unpredictability of a password in bits. A 16-character password with letters, digits, and symbols has ~105 bits of entropy, requiring 2104 average guesses ($10^{31}$ operations), taking centuries to crack even on supercomputers.
